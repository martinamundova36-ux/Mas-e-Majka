# Masáže Majka

Slovenská statická stránka pripravená na GitHub Pages.

## Spustenie
Settings → Pages → Deploy from a branch → main / root.

## Úpravy
Texty a ponuka: index.html. Dizajn: style.css. Fotografie: images/.

## Rezervácie
Formulár je len ukážka: neodosiela ani neukladá údaje a neposiela potvrdenia. Pred reálnym použitím treba pripojiť bezpečný backend, databázu, administráciu a e-mailovú službu. Overiť tiež cenník, kontakty, otváracie hodiny a GDPR informácie.

## Doména
Vlastnú doménu možno nastaviť v GitHub Pages a DNS. Presmerovanie pôvodnej Webnode stránky závisí od jej správy.
